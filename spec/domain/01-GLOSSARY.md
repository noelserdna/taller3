# 01 — Glosario

| Término | Definición (≤ 20 palabras) | No usar |
|---|---|---|
| Taller | El único taller de cerámica; tiene título, número de plazas y dos listas (ENT-001) | curso, clase, evento |
| Plaza | Sitio disponible en el taller; su número total es `plazas` | cupo, aforo |
| Persona | Quien usa la página, identificada solo por el nombre que escribe | usuario, alumno, asistente, participante |
| Organizadora | Rol de quien gestiona el taller desde la sección Organización (RN-002) | administrador, admin |
| Organización | Sección de la página para ver las listas y cambiar las plazas | panel, backoffice |
| Nombre | Texto que identifica a una persona; se recorta y no distingue mayúsculas (RN-003) | alias, apodo |
| Apuntados | Lista ordenada de nombres con plaza confirmada; nunca supera las plazas | inscritos, confirmados |
| Lista de espera | Lista ordenada por llegada de nombres sin plaza; la primera persona es la siguiente en entrar | cola, reservas |
| Puesto | Posición (desde 1) de un nombre en la lista de espera | turno, número de cola |
| Apuntarse | Enviar un nombre para entrar en apuntados o, si no hay plazas, en la lista de espera | inscribirse, reservar |
| Darse de baja | Quitar un nombre de apuntados o de la lista de espera | cancelar, borrarse |
| Promoción | Paso automático de la primera persona de la lista de espera a apuntados al quedar plazas libres | ascenso, subida |
| Aviso de plaza | Mensaje "Plaza confirmada para {nombre}" mostrado al reabrir la página tras una promoción (RN-008) | notificación, alerta |
| Resultado | Tipo de respuesta de una operación (confirmada, espera, duplicado, baja, vacio, plazas, plazas-invalido, plazas-minimo) | respuesta |
| Almacén compartido | Datos del taller que guarda el servidor de la aplicación y ven todos los dispositivos (ENT-002) | base de datos, nube |
| Dispositivo | Navegador desde el que se abre la página; solo recuerda el nombre usado al apuntarse (ADR-005) | equipo, terminal |
