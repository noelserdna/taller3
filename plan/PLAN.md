## 1. Resumen

Una web Vite + JavaScript con un servidor propio (middleware de Vite + fichero JSON) que guarda las listas compartidas. Una sola entrega entrega todo el recorrido.

| FASE | Incremento | Requisitos | Depende de |
|------|-----------|------------|------------|
| FASE-0-SKELETON | Apuntarse, esperar, darse de baja, promoción, organización y datos compartidos entre dispositivos | REQ-F-001..009, REQ-NF-001, REQ-C-001, REQ-C-002 | — |

## 2. Contexto técnico

| Aspecto | Decisión | Ref |
|---------|----------|-----|
| Stack | JavaScript ES modules + Vite + Vitest | AGENTS.md, REQ-C-002 |

## 3. Decisiones (sin preguntar, `--skip-clarify`)

| Id | Decisión | Motivo |
|----|----------|--------|
| D-PA-001 | API en el mismo origen que Vite: `GET /api/taller`, `POST /api/apuntar {nombre}`, `POST /api/baja {nombre}`, `POST /api/plazas {plazas}`; respuesta `{plazas, apuntados[], espera[], resultado}` | REQ-C-002: sin servicios externos; el `server` del perfil es solo Vite |
| D-PA-002 | Dos secciones en una página: principal y «Organización» (enlace `#organizacion`), ambas visibles a cualquiera | REQ-F-007 (sin autenticación) |
| D-PA-003 | Nombre normalizado (trim, sin distinguir mayúsculas) para detectar duplicados; la baja es por nombre e idempotente | REQ-F-002 AC3, REQ-F-005 AC3 |
| D-PA-004 | Promoción visible: el cliente guarda `{nombre, estado}`; al abrir, si pasó de espera a apuntado muestra «Plaza confirmada para {nombre}» | REQ-F-006 |
| D-PA-005 | Plazas iniciales 10; fichero de datos configurable con `TALLER_DATA` (tests usan un temporal) | REQ-F-001 |
| D-PA-006 | Escrituras serializadas en el servidor (un proceso, operaciones síncronas sobre el estado y volcado a disco) | consistencia entre dos clientes |

## 4. Arquitectura

```
Navegador A ─┐                       ┌ src/domain/taller.js (reglas puras)
Navegador B ─┼─ HTTP /api/* ─ Vite ──┤ src/server/store.js  (data/taller.json)
(localStorage: nombre+estado)        └ src/server/api.js    (middleware)
index.html + src/ui/main.js ── src/messages.js
```
